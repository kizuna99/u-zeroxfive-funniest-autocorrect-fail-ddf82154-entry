A single-line autocorrect fail in 73 characters: a formal business email
whose apology for "any inconvenience" was sent as an apology for "any
incontinence". `main.py` writes the line to `/output/entry.txt`. It was
chosen from 16 candidates in a criteria-ordered tournament (one-line
autocorrect fail; funny on first read with a clear, surprising wrong word;
reads as a real slip, not a written joke; clear without explanation in one
line; specific, original wrong word) and refined over five measured
iterations — the tightest version won, since an exact tie goes to the
smaller text.
